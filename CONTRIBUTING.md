# Contributing to OpenML Lab

Thanks for your interest in improving OpenML Lab.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make small, focused changes.
4. Write or update tests for changed behavior.
5. Run `npm test` and `npm run build` before submitting a pull request.
6. Open a clear pull request with a description of the change and why it matters.

## Code standards

- Use TypeScript and keep code type-safe.
- Favor simple, readable components over unnecessary abstraction.
- Keep the UI responsive and accessible.
- Avoid introducing paid services or non-free dependencies in core functionality.

## Issue reports

When reporting a bug or suggesting a feature, include:

- a concise title,
- reproduction steps,
- expected behavior,
- actual behavior,
- browser and OS details when relevant.

## Review expectations

Maintainers review pull requests for correctness, clarity, and alignment with the project goals.

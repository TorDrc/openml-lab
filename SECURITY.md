# Contributing to OpenML Lab

Thanks for helping improve the project.

## Workflow

1. Fork the repository.
2. Create a focused feature branch.
3. Make small, well-scoped changes.
4. Add or update tests when behavior changes.
5. Run `npm test` and `npm run build` before opening a PR.
6. Submit a pull request with a clear description of the change.

## Standards

- Keep the code readable and type-safe.
- Favor simple components and clear utility functions.
- Avoid paid dependencies in core functionality.
- Preserve a responsive, accessible UI.

## Reporting issues

Include:

- expected behavior
- actual behavior
- reproduction steps
- browser or OS details if relevant
